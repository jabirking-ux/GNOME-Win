# GNOME-Win
Work in progress: running GNOME Web (Epiphany) on Windows via a WebKit WinCairo compatibility shim.
**Not functional as a browser yet** - see [PORTING_STATUS.md](PORTING_STATUS.md) and [ARCHITECTURE.md](ARCHITECTURE.md).
Epiphany is GPL-3.0+; WebKit is LGPL/BSD; the bundled Playwright WebKit build is Apache-2.0 (patches) over WebKit.
